# Start creating with Mensa

Download the ZIP from the [tools page](https://nosimaj.com/tools/#mensa), keep it zipped, and upload it as a personal Skill in ChatGPT. Load Mensa Community Engine and describe what you want.

Try: “Mensa carries a birthday cake through an empty PS2 parking lot at night. One image.”

Name PS2 or Late-Z if you already know the style. For a cinematic, the Engine creates a first frame. Reply Approved, then review the storyboard. When that is right, tell it which video tool you use. It prepares the prompt and explains which images to upload.

If something is wrong, say “Change only the feet” or describe the correction. Keep the good parts. For a standalone picture, you can stop after that picture.
