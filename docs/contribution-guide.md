# Contributing

Keep creator instructions short and beginner-friendly. Changes should fix a demonstrated problem or add an explicitly supported workflow. Include the prompt, references, style, and observed failure for repairs; distinguish sampled-frame review from full motion/audio review.

Run both validation scripts. Do not replace source images silently, copy game screenshots into the package, introduce a provider dependency for ordinary image work, or change public/private access settings. Retain Nosimaj attribution for architecture.
