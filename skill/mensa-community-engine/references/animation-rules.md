# Animation rules

Animate approved imagery without redesign. Preserve Mensa face/hair, flat rectangular top, four corner supports, feet, proportions, selected style, props, geography, screen direction, and action state.

## Mensa motion construction

- Walking: short alternating steps and small weight shifts across four supports; stable top, no conventional crawling torso.
- Held power-up: all four feet planted; aura/environment supplies escalation while anatomy stays fixed.
- Carrying: object visibly rests on top; keep contact and balance, no fusion or levitating props unless requested.
- Stacking: distinct bodies with clear contact and counts. Avoid a moving stack with hidden intersections for the first test.
- Jump/levitation: whole body moves along one clear path; no support disappearance.
- Object use: no invented hands, fists, palms, gripping toes, or human standing pose. Resolve unsupported hand actions with the user before altering the premise.

These are staging preferences, not validated Mensa video results. Honor more complex explicit requests and simplify the shots first.

## Cadence

PS2: slightly rigid skeletal steps, readable key poses, basic tracking/pans, fixed cuts, simple sprite effects. Late-Z: held inked poses, brief stepped bursts, impact cels, strong shot-scale contrast. Do not mix them by default.

Tag multi-shot beats HOLD, BURST, INSERT, or REVEAL. Give each one dominant channel: SUBJECT, CAMERA, or EFFECTS. Equal-size panels are not equal durations. Avoid constant orbiting, simultaneous aggressive effects/camera/body motion, and a slideshow when action was requested.

## Model-neutral brief

```text
DURATION / FORMAT / SELECTED STYLE:
VISUAL AUTHORITY / REFERENCE ROLES:
MOTION PROFILE / STATE CHANGE:
AUDIO INTENT:
SHOT [n]: rhythm role; dominant motion; camera; subject action;
environment response; spatial state; transition
CONTINUITY / ESSENTIAL NEGATIVES / LOOP CONDITION:
```

For a simple one-take loop use one continuous behavior, camera rule, return pose, and audio intent rather than unnecessary time blocks. One 360-degree rotation means exactly one turn, same anatomy and scale, final view matches initial.

## Audio and prompt compression

Default NO MUSIC means ambience/effects allowed, no score or song. NO AUDIO means silence. Carry user choices across reruns. Do not claim the result is music-free from its prompt alone. Verify audio only with a supported check.

Keep identity/anatomy first, then central action and contact, shot sequence and geography, style, camera/cadence, decisive negatives, and optional atmosphere. Count final prompt including whitespace when a character limit is requested. A timing number guides the model; it does not guarantee exact delivered duration.
