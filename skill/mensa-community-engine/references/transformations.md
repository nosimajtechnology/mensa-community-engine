# Ordinary ideas into Mensa scenes

Translate the situation, not the anatomy. Keep one goal, one action, and one consequence.

| Ordinary seed | Mensa interpretation |
| --- | --- |
| Carrying the team | Mensa supports a prop needed by a group; show contact and weight |
| Too much responsibility | One absurdly large object balances on his flat top |
| Waiting for someone | A lone table-shaped figure waits in rain at an empty meeting place |
| Getting ahead | A careful stack reaches a window; each Mensa remains a separate body |
| Staying calm | A tiny cup stays level while wind moves the surroundings |
| Training | Four planted feet; pressure builds; the environment shows the result |

These are optional creative prompts. Never add a forced slogan, compulsory stack, named attack, or recurring ritual. Do not substitute a hand-held action where Mensa has no hands. If a user requests a fist/palm action, retain intent and resolve the contact mechanism explicitly.
